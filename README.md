# Chrome拡張機能

このフォルダーには、現在2つのChrome拡張機能があります。

## 共通の使い方

### インストール

1. Chromeで `chrome://extensions` を開く。
2. 右上の「デベロッパーモード」を有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ。
4. 使用する拡張機能のフォルダーを個別に指定する。

指定するフォルダー:

- `Outputs/ChromeExtension/PageOutline`
- `Outputs/ChromeExtension/FocusReader`

`Outputs/ChromeExtension` 自体ではなく、各拡張機能のフォルダーを指定します。

### 更新

ソースコードを変更した場合は、`chrome://extensions` の対象拡張機能にある更新ボタンをクリックします。対象ページも再読み込みしてください。

### 削除

一時的に無効にする場合は、拡張機能カードのトグルをオフにします。完全に削除する場合は「削除」を選びます。

## Page Outline

ページ内の `h1`〜`h6` から固定目次を作成します。

### 主な操作

- `Alt+I`: 機能のオン／オフ
- 目次項目のクリック: 見出しへ移動
- `▶` / `▼`: 子見出しの折りたたみ／展開
- H1〜H6の一括折りたたみ／展開
- 目次タイトルバーのドラッグ: パネル移動
- 左下のハンドルのドラッグ: パネルサイズ変更

初期状態はオンです。現在位置の見出しも自動で強調されます。

### 対象ページ

通常のWebページ全体が対象です。Chrome内部ページやChromeウェブストアなど、Chromeの制限でContent Scriptを実行できないページでは動作しません。

## Focus Reading

マウス位置周辺以外の色味を抑え、読みたい箇所に集中しやすくします。

### 主な操作

- `Alt+M`: 行フォーカス → 矩形エリアフォーカス → オフ
- `Alt+E`: 文字フォーカスへの切り替え、または矩形エリアの拡大
- `Alt+N`: グレー表示のオン／オフ
- `Escape`: 一時停止／再開

初期状態はオフです。ページを再読み込みすると表示状態は初期化されます。

### 対象ページ

HTTP、HTTPS、`file://` ページが対象です。`file://` ページで使う場合は、拡張機能の詳細画面で「ファイルのURLへのアクセスを許可する」を有効にしてください。

## 使い分け

| 目的 | 使用する拡張機能 |
| --- | --- |
| ページの見出し一覧を確認する | Page Outline |
| 現在読んでいる行や範囲に集中する | Focus Reading |

2つを同時に有効にすることもできます。キーボードショートカットは重複しない設定です。
