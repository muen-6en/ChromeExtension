# Page Outline

ページ内の`h1`〜`h6`から、Redmineの目次のような固定パネルを作成するChrome拡張機能です。

## 読み込み方

1. Chromeで`chrome://extensions`を開く。
2. 「デベロッパーモード」を有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ。
4. この`PageOutline`フォルダーを指定する。

## 操作

- `Alt+I`：機能のオン／オフを切り替える。
- ツールバーの拡張機能アイコンをクリックしても切り替えられる。
- 目次タイトル右端の「オフ／オン」ボタンでも切り替えられる。
- 状態は保存され、開いているタブへ反映される。
- 初期状態はオン。
- 画面左下に機能のオン／オフ状態を常に表示する。

## 動作

- 見出しを文書順に収集し、階層に応じてインデント表示する。
- h1〜h6の階層ごとに「▶／▼」ボタンで子階層を折りたためる／展開できる。
- 目次タイトル下でH1〜H6の対象階層を選択し、その階層をまとめて折りたためる／展開できる。
- 深い階層を選択したときは、対象項目が見えるように親階層を自動展開する。
- 一括折りたたみの下にある「強調: オン／オフ」で、現在位置と親見出しの強調表示を切り替えられる。
- 非表示の見出しと拡張機能自身が挿入した要素は除外する。
- `id`のない見出しには一意の`id`を付与する。
- 項目をクリックすると、固定ヘッダーを考慮して約80px下へスムーズスクロールする。
- スクロール中は現在位置の見出しを強調する。
- 現在の見出しは文字色と背景色、上位の親見出しは背景色だけで強調する。
- 強調中の見出しが一覧外へ移動した場合、目次リストもその項目が見える位置へ自動スクロールする。
- DOM変更とURL変更を検知し、約300ms単位で目次を再構築する。
- 見出しがないページでは「見出しがありません」と表示する。
- 見出し一覧が長い場合は、目次パネル内をスクロールできる。
- 目次UIはShadow DOM内に配置し、ページ側CSSの影響を受けにくくしている。
- 目次パネル左下のリサイズハンドルをドラッグすると、幅と高さを変更できる。
- 目次タイトルバーをドラッグすると、パネルを画面内で移動できる。
- 目次パネルはOpacity 0.9で表示し、背後のページがうっすら見える。

## 制限

- Chrome内部ページやChromeウェブストアなど、Content Scriptを実行できないページでは動作しない。
- `file://`のページで使用する場合は、拡張機能の詳細画面で「ファイルのURLへのアクセスを許可する」を有効にする。
- ページ側が極端に特殊なDOM操作を行う場合、見出しの再構築に遅延が発生することがある。
