# Focus Reading

マウスを載せた行だけを通常の色で表示し、それ以外を透明度のあるグレーで抑える Chrome 拡張機能です。

## 読み込み方

1. Chrome で `chrome://extensions` を開く。
2. 右上の「デベロッパー モード」を有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ。
4. この `Outputs` フォルダーを指定する。

## 使い方

- 初期状態は機能オフです。
- 画面左下に現在のモードが表示されます。
- Webページ上でマウスを移動すると、カーソルがある文字行だけが通常の色で表示されます。
- フォーカス行の上下には4pxの余白があり、紺色の枠で囲まれます。
- `Alt+M` で、行フォーカス → 矩形エリアフォーカス → 機能オフの順に切り替えられます。
- `Alt+E` で、行フォーカスと3文字分の文字フォーカスを切り替えられます。矩形エリアモード中は拡大切り替えとして動作します。
- `Alt+N` で、各フォーカスモードのグレー表示だけをオン／オフできます。枠は表示されたままです。
- 文字フォーカスでは、マウス位置を含む3文字と余白だけを通常表示します。
- 文字フォーカスの最小サイズは幅80px・高さ32pxです（画面より大きい場合は画面内に収めます）。
- 文字フォーカスの最大サイズは幅240px・高さ64pxです。
- 矩形エリアモードでは、画面幅30%、表示高さ20%の範囲をマウスの上側に表示します。矩形の下辺がマウス位置に接します。
- 矩形エリアの最小サイズは幅320px・高さ120pxです（画面より大きい場合は画面内に収めます）。
- 矩形エリアモード中に `E` キーを押すと、表示幅・高さがそれぞれ2倍になる拡大モードに切り替わります。
- 行モード中は十字カーソル、矩形エリアモード中はセル選択カーソルを表示します。
- 文字モード中は小さなドット型カーソルを表示します。
- 文字行を取得できない画像などでは、対象要素の矩形を通常表示します。
- `Escape` キーで表示を一時停止・再開できます。
- ページを再読み込みすると表示状態は初期化されます。

## 制限

- Chrome の新しいタブ、Chrome ウェブストア、`file://` ページなどには適用されません。
- 行の高さはページのフォントやレイアウトに依存します。
- 現在はポップアップ設定画面や色味の強さの保存機能はありません。
